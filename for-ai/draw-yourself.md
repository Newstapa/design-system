# 뉴스타파 그래픽: 엔진 없이 직접 그릴 때 (ChatGPT·Gemini 등)

이 문서는 뉴스타파 그래픽 엔진(`engine/`, `scripts/render.py`)을 실행할 수 없는 AI용입니다.
먼저 `guide.md`(디자인 가이드)를 읽고, 아래 순서로 그래픽을 직접 만듭니다.

- 가이드: https://raw.githubusercontent.com/Newstapa/design-system/main/guide.md
- 색·크기 원본: https://raw.githubusercontent.com/Newstapa/design-system/main/assets/tokens.json
- 로고(투명 PNG): https://raw.githubusercontent.com/Newstapa/design-system/main/assets/logo.png

## 1. 먼저 정할 것 (그리기 전에 기자에게 한 줄로 보여주기)

- 핵심 메시지 한 문장 → 제목
- 그래픽 유형 (가이드 6장 표에서 선택)
- 강조할 항목 1~2개
- 출처

기사에 숫자나 출처가 없으면 그리지 말고 기자에게 묻습니다. 숫자를 지어내지 않습니다.

## 2. 그리는 방법

할 수 있는 것 중 위에 있는 방법을 씁니다.

1. **Python으로 이미지 만들기** (코드 실행이 되는 경우)
   - 크기: 가로 1000px로 저장, JPG, 흰 배경.
   - 글꼴: Pretendard가 없으면 시스템의 한글 글꼴(Noto Sans CJK KR, NanumGothic 등)을 지정합니다. 한글이 네모로 깨지면 반드시 글꼴을 다시 지정합니다.
   - matplotlib 기본 스타일을 쓰지 말고 아래 '반드시 지킬 것'을 하나씩 적용합니다 (테두리 상자·격자 실선·범례 상자 끄기).
2. **HTML 한 파일로 만들기** (미리보기나 캔버스가 있는 경우)
   - 가로 1000px 고정 상자 안에 SVG 또는 HTML로 그립니다. 외부 차트 라이브러리 기본 테마를 쓰지 않습니다.
3. **둘 다 안 되면** `for-ai/json-spec.md` 형식의 JSON을 만들고, 기자에게 웹 렌더러에 붙여넣으라고 안내합니다.
   웹 렌더러: https://newstapa.github.io/design-system/web/

## 3. 반드시 지킬 것 (체크리스트)

- [ ] 맨 위 굵은 가로선(2px, #222222), 맨 아래 가는 가로선(1px, #222222)
- [ ] 제목 40px 굵게 #111111, 왼쪽 정렬 / 부제 24px #888888
- [ ] 로고 오른쪽 위 (로고를 못 넣으면 그 자리에 회색 "뉴스타파" 글자)
- [ ] 강조 1~2곳만 포인트 색(기본 주황 `#FF723D`), 나머지 데이터는 `#C4C4C4`(막대) 또는 `#6B6B6B` `#9A9A9A` `#E0E0E0`
- [ ] 강조값 글자는 `#D9531F` 굵게
- [ ] 값은 데이터 바로 옆에 직접 표시, 색 상자 범례 대신 계열 이름을 그 색 글자로
- [ ] 격자는 연한 점선(#C9C9C9) 또는 없음, 0 기준선만 실선
- [ ] 차트 테두리 상자, 그림자, 3D, 그라데이션, 어두운 배경 없음
- [ ] 단위는 첫 값에만 또는 오른쪽 위 '단위: …'
- [ ] 왼쪽 아래 `* 출처 : …` (주석이 있으면 그 위에 `* …`)
- [ ] 글자 크기: 라벨 19, 값 20(굵게), 축 17, 출처 17 (1000px 기준)

## 강조색

기본은 주황입니다. 결과를 전할 때 "빨강·파랑·초록 강조색 버전도 가능하다"고 안내하고, 기자가 고르면 아래 세 값을 통째로 바꿔 다시 그립니다.

| 빨강 | #E0393E | #B3262B | #F8D0D1 |
| 파랑 | #2F6FD6 | #1F55AA | #D4E2F7 |
| 초록 | #23986A | #17734F | #CBEBDD |

## 4. 다 그린 뒤

이미지를 직접 다시 보고 글자 겹침·잘림·한글 깨짐이 없는지 확인한 뒤 전달합니다.
전달할 때 "무엇을 강조했는지" 한 줄과 함께, 정확히 같은 디자인이 필요하면 웹 렌더러를 쓰라고 안내합니다.
