AI가 만든 JSON을 붙여넣으면 뉴스타파 디자인 가이드대로 그래픽을 만듭니다.

디자인 가이드 GitHub 스킬 다운로드
  1. 1AI에게 요청하기 지침 주소가 담긴 짧은 요청문을 복사해 AI 대화창에 붙여넣고, 기사를 덧붙이세요.
    AI가 "주소를 열 수 없다"고 하면 '전체 지침 복사'를 쓰세요.
  2. 2JSON 붙여넣기 AI가 준 답을 통째로 아래 JSON 칸에 붙여넣으면 바로 미리보기가 바뀝니다.
  3. 3확인하고 저장 숫자·출처를 확인하고 JPG로 저장하세요. 글자 크기·색을 손보려면 '디자인 조정' 탭을, 일러스트레이터에서 고치려면 SVG 저장을 쓰세요.

기사 미리보기

미리보기 · 기사 본문에 들어갔을 때의 모습

뉴스타파 취재진이 입수한 자료를 분석한 결과, 지난 5년간 관련 예산은 꾸준히 늘었지만 실제 집행률은 해마다 낮아진 것으로 나타났다. 담당 부처는 "사업 구조를 개편하는 과정에서 생긴 일시적인 현상"이라고 해명했지만, 전문가들은 집행 관리 체계 자체에 문제가 있다고 지적한다.

특히 지역별로 보면 차이가 더 뚜렷했다. 일부 지역은 배정된 예산의 절반도 쓰지 못했고, 반대로 몇몇 지역은 추가 예산을 요청할 만큼 수요가 몰렸다. 아래 그래픽은 그 차이를 한눈에 보여준다.

그래픽에서 보듯 격차는 일시적인 현상이 아니라 몇 년째 이어지고 있다. 한 지자체 관계자는 "현장의 수요를 제대로 반영하지 못한 채 예산이 일률적으로 나뉘고 있다"고 말했다.

뉴스타파는 관련 부처에 구체적인 개선 계획을 물었으나, 기사 마감 시점까지 답을 받지 못했다. 취재진은 후속 보도를 통해 예산 배분 과정을 더 자세히 살펴볼 예정이다.

스킬 적용 방법

스킬을 한 번 등록해 두면, Claude에 기사를 붙여넣고 "시각화해줘"라고만 해도 뉴스타파 디자인으로 JPG를 만들어 줍니다.

  1. 스킬 파일 받기 오른쪽 위 스킬 다운로드로 newstapa-graphics.zip을 받습니다. 압축은 풀지 않습니다.
  2. Claude에 올리기 (나만 쓰기) claude.ai → Customize → Skills → + → Create skill → Upload a skill에서 zip을 고릅니다.
  3. 조직 전체에 배포하기 (관리자) Team·Enterprise 소유자는 Organization settings → Plugins & skills → Organization skills의 + Add로 올리면 전 직원에게 바로 생깁니다.
  4. 코드 실행 켜져 있는지 확인 스킬은 코드 실행으로 그림을 만듭니다. Organization settings → Plugins & skills → Policy에서 Code execution and file creation과 Skills가 켜져 있어야 합니다.
  5. 써 보기 새 대화를 열고 기사나 데이터를 붙여넣은 뒤 "시각화해줘"라고 씁니다. 다른 강조색이나 일러스트용 SVG가 필요하면 이어서 요청하면 됩니다.
지침이 바뀌면? 스킬은 실행할 때마다 GitHub의 최신 지침을 읽어 오므로 다시 올릴 필요가 없습니다. 스킬 파일 자체(SKILL.md)가 바뀐 경우에만 새 zip을 다시 올립니다.
ChatGPT·Gemini를 쓴다면? 스킬 대신 AI 지침 칸에 넣을 문구를 맞춤형 GPT·Gem 설정에 붙여넣으세요. 디자인을 정확히 맞추려면 이 페이지에 JSON을 붙여넣어 저장하면 됩니다.
