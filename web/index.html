뉴스타파 그래픽 렌더러

AI가 만든 JSON을 붙여넣으면 뉴스타파 디자인 가이드대로 그래픽을 만듭니다.

  1. 1. AI에게 요청하기 버튼을 누르면 지침 주소가 담긴 짧은 요청문이 복사됩니다. AI 대화창에 붙여넣고 기사를 덧붙이세요.
    AI가 "주소를 열 수 없다"고 하면 '전체 지침 복사'를 쓰세요.
  2. 2. JSON 붙여넣기 AI가 준 JSON 코드 블록을 그대로 아래 칸에 붙여넣으면 바로 미리보기가 바뀝니다.
  3. 3. 확인하고 저장 숫자·출처를 확인하고 경고가 없으면 JPG로 저장하세요.
